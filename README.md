# Sri Vinayaka Flex

Website for Sri Vinayaka Flex, Suryapet — 24-hour flex printing.

- Website: https://sri-vinayaka-flex.vercel.app
- Owner page (upload photos, manage owner emails): https://sri-vinayaka-flex.vercel.app/admin

Owners log in with their email ID and a 6-digit code sent to that email. Uploaded photos float in the
"Our Work" section together with the default photos. No database: photos are stored in Vercel Blob.
Hosted on Vercel; every push to `main` goes live automatically. See [ADMIN_SETUP.md](ADMIN_SETUP.md).
